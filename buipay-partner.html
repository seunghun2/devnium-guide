3. 고객사가 알아야 할 운영 기준

고객사는 초기 예치금 입금(또는 무예치 옵션 선택)만 완료하면 별도 정산·송금 업무 없이 즉시 운영하실 수 있습니다. 핵심 운영 기준은 아래와 같습니다.

1. 부의금 카드결제 CS 처리 기준

부의금 카드결제는 결제 즉시 상주 계좌로 실시간 입금되므로 아래 기준으로 응대합니다.

문의 유형 처리 원칙 상세 응대 기준
1) 단순 변심 · 금액 오입력
결제 취소 요청		 원금 반환 입금 확인 후 취소
(송금완료 후 임의 취소 불가)		 결제와 동시에 상주 계좌로 현금이 입금되므로 당사에서 임의로 회수·취소할 수 없습니다.
- 결제자에게 부의금 원금을 데브늄 지정 반환 계좌(고객센터 별도 안내)로 입금해 달라고 안내합니다.
- 입금이 확인되면 카드 승인 취소를 진행합니다.
2) 예외적으로 즉시 취소가
가능한 경우		 ① 미입금(송금 실패) 건
② 시스템 중복 결제 건		 - 은행 점검·시스템 오류로 상주에게 입금되지 않은 건은 확인 즉시 카드 승인 취소 처리
- 중복 결제 건은 CS팀에서 확인 후 처리합니다.
3) 상주 측 미입금 문의 통장 입금자명 확인 안내 상주 통장에 찍힌 입금자명(조문객 성명)을 안내합니다.
(은행 점검 시간 23:30~00:30 결제 건은 점검 종료 후 순차 입금되므로, 점검 이후 입금될 예정임을 고지합니다.)
4) 카드 명세서 가맹점명 문의 데브늄(주) / 이노페이(INNOPAY) 카드 승인 문자 및 명세서에는 데브늄(주) 또는 결제대행사 이노페이(INNOPAY)로 표기됨을 안내합니다.
5) 결제 및 입금 완료

부의금은 결제와 동시에 상주님 계좌로 바로 전달되는 서비스라, 저희가 임의로 취소하기가 어렵습니다.

안내해 드리는 데브늄 반환 전용 계좌로 부의금 원금을 입금해 주시면, 확인 후 카드 결제를 바로 취소해 드리겠습니다.

▶ 입금 계좌 : 데브늄 지정 반환 계좌 (고객센터 별도 안내)
▶ 예금주 : 데브늄(주)
▶ 입금액 : 결제하신 부의금 원금 (수수료 제외)

※ 카드 취소 후 환급 시점은 카드사에 따라 다를 수 있습니다.
② 상주 측 "입금이 안 들어왔다" 문의 시 
상주님, 삼가 고인의 명복을 빕니다.
확인 결과 [조문객 성명]님께서 [결제 시각]에 결제하신 [금액]원이 상주님의 계좌로 정상 입금 완료되었습니다.
통장 거래내역에서 입금자명 '[조문객 성명]'으로 입금된 내역을 한 번 더 확인 부탁드립니다.

※ 은행 점검 시간(23:30~00:30)에 결제된 건은 점검 종료 이후 순차적으로 입금될 예정입니다.
